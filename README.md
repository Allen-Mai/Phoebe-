# 日记本 + 工作手册

一套**本地优先**的个人记录系统。分成两半：

| | 是什么 | 在哪 |
|---|---|---|
| **图库** | 纯 Markdown 文件，Logseq 直接打开 | `graph/` |
| **网页版** | 零依赖单文件应用，用来浏览、检索、以及用 AI 整理 | `web/index.html` |

日记和工作手册**完全分开**，互不干扰。没有云端、没有账号、没有数据库 —— 你的内容就是磁盘上的 `.md` 文件。

---

## 快速开始

**Windows，双击即可：**

```
工具\启动日记本.bat
```

它会做两件事：启动本地代理（用于 AI 功能），然后打开浏览器。

**只想看看，不装任何东西：**

直接双击 `web\index.html`。零依赖、不联网、不需要 Node / Python / 服务器。

> 区别：直接开 `index.html` 时 **AI 功能不可用**（浏览器跨域限制）。其余全部功能正常。

## 网页版有什么

### 📅 日历

点任意一天，**直接进那天的编辑状态**。写过的日子显示字数与摘要预览，当天有粉色描边。

**未来日期锁死** —— 10 月 7 日写的日记，点 10 月 8 日不会有任何反应，鼠标还变成禁止图标。防止误点往仓库里塞空文件。

### 📜 原文卡片

阅读页的每个小节渲染成**一张独立卡片**：

```
┌──────────────────────────────────────────┐
│ 一、📝 今天做了什么                       │
│ ──────────────────────────────────────── │
│   1. 上午把示例项目的接口文档过了一遍      │
│   2. 下午和张三确认了对齐方式              │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│ 二、💼 工作和进展                         │
│   1. 关于示例项目的一个关键决策：          │
│      • 决定：先不做多语言                  │
│      • 原因：会拖慢第一版上线              │
└──────────────────────────────────────────┘
```

- **框用中文序号**（一、二、三、四……），自动进位到「十」「十一」「二十五」
- **框内条目用数字编号**（1. 2. 3.），只编最外层，子项仍是圆点
- 分框规则认 `#` / `##` / `###` 标题，**也认「原文：」这种顶格+冒号结尾的小节标签**

### 🧮 表格视图

行 = 每一天，列 = **自动从内容里的 `##` 二级标题生成**。想加一列，就在日记里多写一个小标题。

表头、正文标题、左侧导航都会**自动配 emoji**（按关键词匹配，匹配不到就用标题哈希挑一个 —— 用哈希而不是随机数，保证同一标题每次刷新都是同一个 emoji）。

### 🎀 三丽鸥角色

每个页面右上角随机出现一位角色，带一句**中英双语**名言，共 **125 条**。

- 🔊 **点小喇叭朗读** —— 中文、英文各一个喇叭
- 默认用系统语音合成；可在设置里换成**豆包音色**（见下文）
- 点名言可展开全文，默认各截 3 行
- **写日记时，编辑页右上角有库洛米打气动图** + 打气气泡

### 🔍 其他

| 功能 | 在哪 |
|---|---|
| 全文搜索（带命中高亮） | 左侧「🔍 搜索」 |
| 字数热力图 / 连续记录天数 | 左侧「📊 统计」 |
| 反向链接（谁提到过我） | 页面右侧栏 |
| 待办自动汇总、本周工作 | 左侧「✅ 待办总览」「⭐ 本周工作」 |
| 删除页面 / 恢复 | 页面右上「🗑」，侧栏底部「🗑 已删除」可还原 |

## 🪄 AI 提炼（核心功能）

### 编辑页分成两个区

```
┌─ ✨ AI 提炼的小节 ──── 自动生成，不用也不能在这里改 ─┐
│   📝 今天做了什么   💼 工作和进展                   │  ← 只读，没有输入框
│   💗 感受 / 状态     🌟 明天要做                    │
└──────────────────────────────────────────────────────┘

┌─ 📝 原文： ──────────── AI 只读这里，不会改它 ───────┐
│   1、干活：上午把办公室的卫生搞了，倒了烟灰缸…      │  ← 只有这里能写
└──────────────────────────────────────────────────────┘
```

**设计原则：四个小节归 AI，原文归你。**

- 你只写「原文」，AI 每次从原文提炼出 `今天做了什么` / `工作和进展` / `感受 / 状态` / `明天要做`
- 点「💾 保存并提炼」→ 先存原文，再让 AI 重写上面四个小节
- **原文一个字符都不会被改动**
- 只保存、不改原文时不会重复调用 AI（靠顶部记录的原文指纹判断）
- AI 失败不影响保存 —— 原文已经落盘，只是四个小节没更新

### 配置

编辑任意页面 → **⚙️ AI 设置**：

```
接口地址  [ http://127.0.0.1:8787/v1        ]   ← 本地代理
模型      [ deepseek-v4-pro                 ]
API Key   [ 留空（走本地代理）              ]
思考模式  [ ] 开启（更慢更贵，提炼一般用不上）
```

**为什么要代理**：DeepSeek 官方 API 不允许浏览器直接跨域调用。`工具\ai-proxy.ps1` 是一个**手写的 PowerShell HTTP 代理**（不需要 Node），它顺便也把网页本身托管起来，这样页面和接口同源，彻底绕开跨域。

API 密钥放在 `工具\ai-key.txt`（**已 gitignore，不会进版本库**）。

### 🔊 豆包音色（可选）

想让名言用豆包的音色朗读：

1. 去[火山引擎语音合成控制台](https://console.volcengine.com/speech/service/8)开通，拿到 **AppID** 和 **Access Token**
2. 填进 ⚙️ AI 设置 → 名言音色 → 选「豆包（火山引擎）」
3. 中文/英文音色各有一个输入框，带 21 个常用音色下拉，也可以直接粘 `voice_type`

**两个坑（已在代码里处理）**：

- 鉴权头是 `Authorization: Bearer;{token}` —— 中间是**分号不是空格**
- 音色代次和 `resource-id` 必须匹配，配错会「HTTP 200 但 code 55000000、音频是空的」

密钥只存在浏览器 localStorage 里，代理只做转发、不留副本。配错了会弹提示并**自动回退到系统语音**。

## 自带自检

页面顶部横幅会显示 `✅ 自检：38 项通过`。点它看每一项的详情，也可以直接开：

```
http://127.0.0.1:8787/#selftest
```

**这是刻意做进去的排查手段。** 开发过程中它抓到过好几个真 bug，包括：

- 分框规则只认 `#`/`##`，导致 `### 明天要做` 渲染成标题却不分框
- 删除页面时把内容从 `EDITS` 里删掉 → 只存在于浏览器的页面**永久丢失**
- 清理原文时 `skipping` 标志一路吃到文件尾 → **正文被无声删除**

所以改代码前后都建议跑一遍。

## 技术选择

| 选择 | 为什么 |
|---|---|
| **单文件 HTML** | 没有构建、没有依赖、没有 `node_modules`。整个应用就是一个可以双击打开的文件 |
| **Logseq OG，不是 2.x** | 2.x 是数据库版，放弃 `.md` 纯文本、插件与 PDF 导出都不可用。1.x/OG 直接读写 Markdown |
| **PowerShell 代理** | 这台机器没装 Node。代理用 `TcpListener` + `HttpWebRequest` 手写，纯 ASCII 脚本，不依赖任何运行时 |
| **字节透传** | 代理转发原始字节而不是文本 —— `Invoke-WebRequest` 会按 charset 解码，遇到不返回 charset 的接口就毁中文 |
| **localStorage 存修改** | 网页版不直接写磁盘（浏览器沙箱限制）。改动存 localStorage，点「下载 .md」落盘 |
| **CSS 计数器做条目编号** | 编号不写进 `.md` 文件，Logseq 那边看到的仍是干净的纯文本 |

## ⚠️ 隐私

**这个仓库是公开的。** 所以：

- `工具/ai-key.txt`（API 密钥）**已在 `.gitignore` 里**，不会上传
- `graph/` 里目前全是**演示数据**（示例项目、张三、参加启动会）
- **真实日记内容不要放进 `graph/`** —— 否则会公开

要么把仓库改成私有（GitHub → Settings → Danger Mode → Change visibility），要么让 `graph/` 只放演示数据。
