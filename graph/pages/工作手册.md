- # 工作手册
- 这里是工作信息的**唯一查找入口**。日记只写日记，工作内容直接写在这里。
-
- ## 快速入口
  - [[待办总览]] —— 所有未完成、进行中的事
  - [[本周工作]] —— 本周完成与进行中的自动汇总
-
- ## 四大分区
  - ### 1. 速查：项目与人物
    - 项目页用「项目档案」模板新建：在空白块输入 `/template` → 选「项目档案」
    - 人物页用「人物档案」模板新建
    - **查找技巧**：打开某个项目页，页面下方 **Linked References（反向链接）** 会自动列出所有提到过它的日记和手册页 —— 这就是"这件事的完整历史"，不用手动整理
  - ### 2. 跟踪：待办
    - 用 Logseq 原生 `TODO` / `DOING` / `DONE` 标记
    - 建议写在对应的项目页下（这样待办有上下文），[[待办总览]] 会自动汇总
    - 常用状态切换：`Ctrl+Enter` 循环切换 TODO → DOING → DONE
  - ### 3. 沉淀：经验与流程
    - 用「经验 / 流程」模板新建，打上 `#经验` 标签
    - 命名用**你将来会搜的词**，例如「上线前检查清单」而不是「经验 12」
  - ### 4. 取材：写周报月报
    - 新建周报页（命名如 `2026-W41 周报`），用「周报」模板
    - 模板里自带查询，会自动列出过去 7 天标记为 `DONE` 的事项
    - 你的工作是**筛选和措辞**，不是回忆
-
- ## 命名约定
  - 项目页：`项目名`（如 `XX系统改版`），不要加「项目」二字当后缀
  - 人物页：`姓名`（如 `张三`）
  - 经验页：`动作 + 对象`（如 `数据库迁移操作步骤`）
  - 周报页：`YYYY-Www 周报`（如 `2026-W41 周报`）
-
- ## 建议的工作节奏
  - **每天**：写日记（`journals/` 下）—— 随便写，不用管结构
  - **每周一次（约 15 分钟）**：把日记里值得长期留存的工作信息，搬进对应的项目页/经验页；然后生成周报
  - **每月一次**：跑一次 `工具/统计.py` 看记录情况；检查有没有长期挂着的 TODO
